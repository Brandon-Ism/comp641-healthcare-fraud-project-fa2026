# Healthcare Fraud Detection

Classification models to flag fraudulent medical insurance claims using ICD-10 diagnosis and CPT procedure codes.

Group project for COMP 641 at California State University, Northridge, Fall 2026.

## Team

- Seveda Shaghoolian

## Dataset

[Healthcare Fraud Detection Dataset](https://www.kaggle.com/datasets/nudratabbas/healthcare-fraud-detection-dataset) from Kaggle. It contains synthetic medical insurance claims with ICD-10 and CPT codes.
